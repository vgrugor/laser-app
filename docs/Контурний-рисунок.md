# Контурний рисунок для обведення

Після отримання потрібного кольорового декору відкрийте «Результат» або «Збережений виріб» та третю вкладку «Контурний рисунок для обведення» після «Кольоровий декор». Натисніть «Створити контурний рисунок». Якщо параметри вже змінені, спочатку оновіть основні зображення. Після оновлення коду перезапустіть локальний сервер `sh scripts/start.command` та оновіть сторінку браузера.

Це окремий запуск через той самий Codex SDK: спільний контурний рисунок → порівняння з кольоровим декором. Генерація отримує існуючий фронтальний декор й збережений план деталей. Нові концепції та новий план при цьому не створюються.

Один PNG містить разом зовнішні контури, межі вирізаних деталей, отвори, обрамлення та видимі лінії гравіювання. Білий фон і тонкі чорні лінії без заливки, тіней, морилок чи фактури. Між суміжними вставками одна спільна лінія. Межі фізичних деталей замкнені, внутрішні штрихи гравіювання можуть бути відкритими. Темний колір морилки сам по собі не є гравіюванням. В одношаровому виробі внутрішній мотив не перетворюється на інкрустацію.

Рисунок можна збільшити або завантажити. Звіт порівняння розташований у блоці «Перевірка контурного рисунка» й не замінює основну перевірку виробу. Відмінність розмірів PNG у пікселях від master автоматично потрапляє до зауважень навіть при позитивній оцінці моделі.

Створення контурів у погодженому виробі не створює новий проєкт і не скидає погодження. Зміна кольорового декору чи його параметрів позначає старий рисунок як такий, що потребує оновлення. Відповідь генератора не застосовується, якщо джерело змінилося під час виконання. Застарілий рисунок лишається доступним із відповідною позначкою.

Прогрес, скасування, відновлення зв’язку й повторний запуск доступні в цій же вкладці. Якщо рисунок створено, а перевірка не завершилася, PNG зберігається без позитивного звіту. Попередній результат зберігається у версії перед застосуванням нового; для перегляду таких версій може знадобитися режим «Усі версії».

Файл входить до локального збереження, версій та експорту/імпорту JSON. На сервері PNG, промпт, контрольні суми й звіт розміщуються в `artifacts/runs/<job-id>/`, поза Git. Збережені раніше окремі контури різання й гравіювання лишаються в даних та резервних копіях, але не видаються за спільний рисунок: вкладка пропонує створити новий формат.

Генератор може змінити дрібну геометрію. Перед обведенням звірте силует, кількість деталей, кадрування й масштаб із кольоровим декором. Після обведення перевірте у SolidWorks масштаб, замкненість контурів, спільні межі без дублювання та перемички від 2 мм. Вручну призначте лініям операції різання або гравіювання: спільний рисунок не розрізняє їх кольорами чи типами ліній. Це растровий орієнтир, а не готовий SVG/DXF для лазера.
