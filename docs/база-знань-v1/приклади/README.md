# Приклади та їхній статус

Приклади демонструють художні рішення й помилки. Жоден не має підтвердження виготовлення або виміряної геометрії.

| Приклад | Оцінка користувача | Технічний статус |
|---|---|---|
| [Підставка з птахом v3](підставка-птах/README.md) | Вигляд із рамкою оцінено як кращий, взятий за візуальний орієнтир | Старий приклад перед строгим уточненням чорного гравіювання; перевірити перед повторним використанням |
| [Ключниця з двома синицями v3](ключниця-синиці/README.md) | Остання версія не має прямого фінального схвалення | Прибрано світле гравіювання, змінено дзьоби; геометрію та кріплення не перевірено |
| [Шкатулка з магнолією v1](шкатулка-магнолія/README.md) | Користувач прямо повідомив «Мені подобається» | Візуально схвалено, не виробничо перевірено |

У кожній папці є фронтальний декор, вигляд виробу й історичні нотатки з промптами. Історичні нотатки не переписані заднім числом: їхній старий статус може відрізнятися від актуального README. Поточні правила бази мають перевагу над старими промптами.
