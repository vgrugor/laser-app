# Морилки та складання

ОБОВ'ЯЗКОВО: гравіювання → різання → фарбування окремих деталей → приклеювання на підкладку → лакування.

Морилка розтікається, тому не проєктувати чітко розмежовані різні кольори на одній фізичній деталі. Морилки не змішувати. «Чистий» означає пропуск нанесення морилки, а не білу фарбу. Видима деревна фактура не означає додаткове оздоблення.

У карті частин зазначати ID палітри й операції. Підкладка, фонові частини, вставки, рамка, корпус і фурнітура повинні мати зрозуміле місце в складанні.

РЕКОМЕНДАЦІЯ: не закладати елементи, які незручно тримати й фарбувати. Не додавати неперевірені рецепти клею, марки лаку чи режими лазера: користувач їх не задавав.
