# Панно та ікони

Типові габарити користувача — до приблизно 200 × 300 мм, із прагненням економно використовувати лист. Фанера 3 мм; один шар або підкладка з інкрустацією.

РЕКОМЕНДАЦІЯ: композиція читається на відстані; обрамлення та орнамент підпорядковані головному образу. Для людини додати файл об'єкта «Людина». Враховувати референс, важливі символи та впізнаваність без вигадування жорсткого іконографічного канону. Конкретна традиція зображення й спосіб підвішування НЕ ВИЗНАЧЕНІ й уточнюються за потреби.
