# Підставка для чашки

Підтверджений типовий формат — круг Ø100 мм. Без інкрустації один шар, з інкрустацією підкладка та верхній декор. РЕКОМЕНДАЦІЯ: верхня поверхня рівна, без випадково піднятих мотивів; дрібні деталі спрощувати відповідно до масштабу.

Перевіряти форму зовнішнього краю, місце мотиву, відступи до рамки й практичність дрібних частин. Гравійована рамка та вирізана рамка ≥2 мм однаково дозволені. Конкретні 0,7 мм штриха й відступи 3 мм у прикладі птаха не переносити автоматично на інші вироби.
